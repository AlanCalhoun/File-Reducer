# File-Reducer

Shrink oversized CSV extracts so they are easier to open, inspect, and move through ops workflows.

Originally written as a Jupyter notebook with a desktop `.bat` launcher for one-click runs.

## Features

- Reduce large CSV files for faster local handling
- Notebook workflow for inspection
- Optional Windows `.bat` launcher

## Requirements

- Python 3.x
- Jupyter

## Usage

1. Open `File Reducer.ipynb` and point it at your CSV, **or**
2. Run `Run File Reducer .BAT` from the desktop if you keep a local shortcut.
